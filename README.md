# Election Pipeline

Plataforma de engenharia de dados para acompanhamento
dos resultados eleitorais brasileiros a partir de fontes
oficiais do Tribunal Superior Eleitoral (TSE).

## Objetivos

- Coletar dados eleitorais oficiais.
- Processar resultados por candidato e unidade federativa.
- Acompanhar votos contabilizados e progresso da apuração.
- Disponibilizar os dados por uma API REST.
- Desenvolver um dashboard interativo.
- Informar a fonte e o horário da última atualização.

## Tecnologias

- Python
- Pandas
- FastAPI
- PostgreSQL (etapa futura)
- Next.js e TypeScript (etapa futura)
- Pytest
